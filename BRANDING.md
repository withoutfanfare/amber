# Database Snapshot Manager — Branding Ideas

## Overview
Git-like version control for local development databases. Built with Tauri 2 + Rust for developers who need confidence before every migration.

---

## Name Ideas

### Primary Recommendation
**Timemachine** — Evokes Apple's backup tool (familiar, trusted) but specifically for databases. Suggests rewinding to any point in time. Simple, memorable, descriptive.

### Alternative Names

| Name | Rationale |
|------|-----------|
| **Checkmate** | Checkpoints for your database; also "check" + "mate" (friend/helper) |
| **Rewind** | Direct promise: go back to any previous state |
| **Snapdragon** | Playful, memorable; dragon guarding your data snapshots |
| **Statecraft** | Crafting/keeping state; sounds capable and developer-focused |
| **Docket** | Small document/record; also dock-like stability |
| **ChronoDB** | Time + database; sounds technical and precise |
| **Safeguard** | Direct promise of protection |
| **Branchline** | Git metaphor + database line/connection |
| **Snapshot** | Simple, descriptive, to the point |
| **VaultDB** | Security, preservation, access control |
| **Memoria** | Latin for memory; elegant, timeless |
| **Preserve** | Direct description of core function |

## Visual Direction

### Mood & Aesthetic
**Technical precision meets playful confidence**

The visual language should feel:
- **Developer-native** — understands the workflow, speaks the language
- **Reliable** — solid, dependable, never flashy
- **Fast** — suggests speed and efficiency
- **Smart** — intelligent features, thoughtful UX
- **Approachable** — not enterprise-stuffy, not toy-like

### Visual References
- Developer tools (GitHub Desktop, Tower, Sourcetree)
- Modern database tools (TablePlus, Beekeeper Studio)
- System utilities (CleanMyMac, DaisyDisk)
- Precision instruments (camera apps, audio tools)

### Logo Concepts

#### Concept 1: The Hourglass Database
A stylised database cylinder combined with hourglass/time elements. Suggests time-based snapshots of data.

#### Concept 2: The Branching Cylinder
Git-style branching diagram merged with a database cylinder icon. Immediately communicates "version control for databases."

#### Concept 3: The Shield + Data
A protective shield element combined with abstract data bars or grid. Emphasises safety and security.

#### Concept 4: The Crystal/Save Point
Video game "save point" crystal aesthetic — developer-nostalgic, suggests preservation of state.

#### Concept 5: The Snapshot Star
Camera aperture or starburst combined with database elements. Suggests capturing a moment in time.

## Colour Palette

### Primary Palette

| Role | Colour | Hex | Usage |
|------|--------|-----|-------|
| Primary | Electric Indigo | `#4f46e5` | Primary actions, brand identity |
| Secondary | Mint Green | `#10b981` | Success, restore, positive states |
| Accent | Warm Amber | `#f59e0b` | Warnings, attention, snapshots |
| Dark | Slate 900 | `#0f172a` | Text, backgrounds |

### Extended Palette

| Role | Colour | Hex | Usage |
|------|--------|-----|-------|
| Light | Slate 50 | `#f8fafc` | Backgrounds |
| Accent Alt | Rose 500 | `#f43f5e` | Destructive actions, danger |
| Neutral | Slate 400 | `#94a3b8` | Secondary text, borders |
| Highlight | Cyan 400 | `#22d3ee` | Information, links |

### Dark Mode Variant

| Role | Colour | Hex |
|------|--------|-----|
| Background | Slate 950 | `#020617` |
| Surface | Slate 900 | `#0f172a` |
| Primary | Indigo 400 | `#818cf8` |
| Success | Emerald 400 | `#34d399` |

### Rationale
Indigo suggests technology and intelligence. Mint green for success/restores creates a fresh, positive association. The palette works well in both light and dark modes (essential for developer tools).

## Typography

### Primary Typeface: **JetBrains Mono** or **SF Mono**
Monospace for that authentic developer tool feel. Highly legible at small sizes.

### UI Typeface: **Inter** or **Plus Jakarta Sans**
Clean sans-serif for UI elements, labels, and non-code content.

### Headings: **Space Grotesk** or **Satoshi**
Slightly technical/geometric sans-serif for headings — modern but distinctive.

## UI Patterns

### Snapshot List
- Card-based layout with clear visual hierarchy
- Colour-coded status indicators
- File size displayed prominently
- One-click restore actions

### Diff Viewer
- Split-pane or inline diff (configurable)
- Syntax highlighting for SQL
- Row-level highlighting (green/red)
- Search and filter capabilities

### Branching Visualisation
- Git-style branch graph
- Clear lineage and parent relationships
- Merge point indicators
- Branch switching with visual feedback
